# Exploratory Data Analysis Methods

Exploratory Data Analysis, or EDA, is the process of understanding a dataset before modeling or decision-making. EDA checks data structure, quality, distributions, relationships, and potential business patterns.

A typical EDA workflow starts with dataset overview: number of rows, number of columns, missing cells, duplicate rows, and memory usage.

The next step is field profiling. Each column should be classified as numerical, categorical, datetime, text, ID, or target variable. This classification determines which analysis methods are appropriate.

Data quality analysis checks missing values, duplicate rows, constant fields, high-cardinality fields, outliers, and target imbalance.

Univariate analysis studies one field at a time, such as numerical histograms or categorical count charts.

Bivariate analysis studies relationships between two fields, such as target rate by category, scatter plots, or correlations.

EDA should produce actionable next steps, such as cleaning recommendations, segmentation ideas, modeling warnings, and additional questions for domain experts.
