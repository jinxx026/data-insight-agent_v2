# Visualization Guide

Chart selection should depend on field types and analysis goals.

Use histograms for numerical distributions. Histograms help reveal spread, skewness, peaks, and unusual values.

Use box plots for numerical features when comparing distributions or spotting potential outliers.

Use bar charts for categorical distributions. Bar charts help show the most common categories and whether one category dominates.

Use grouped bar charts to compare a target variable across categories. For example, churn rate by contract type can reveal customer segments with higher churn risk.

Use line charts for time trends. Datetime fields enable monthly, weekly, or daily aggregation to show changes over time.

Use heatmaps for correlation matrices or two-dimensional intensity comparisons.

Avoid pie charts when there are many categories. Bar charts are usually easier to compare and read.
